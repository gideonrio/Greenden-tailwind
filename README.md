# 🌿 GreenDen – Plant Shopping Website

GreenDen is a modern plant shopping website developed using **HTML5 and Tailwind CSS**. It provides a clean and user-friendly interface for exploring plants, browsing products, and discovering beautiful greenery.

## 🚀 Project Overview

GreenDen is a frontend development project designed to demonstrate practical skills in HTML, Tailwind CSS, responsive layouts, and modern web design.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS 2.2.19
- Font Awesome

## ✨ Features

- Clean and modern user interface
- Home page with attractive design
- Product listing page
- Contact page
- Plant product gallery
- Product names and pricing
- Interactive hover effects
- Responsive website layout
- Tailwind CSS utility-based styling

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the project

Open the cloned project folder in Visual Studio Code.

### 3. Run the website

Open `index.html` using the VS Code Live Server extension.
